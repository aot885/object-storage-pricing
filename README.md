"按量付费"四个字听起来很清爽——用多少付多少。但真到计费页上，常见的收费项至少有四类：存储容量、请求次数、外网下行流量，以及低频/归档存储的取回费和最低存储期限。有些厂商还会把 HTTPS 请求、跨区域复制、CDN 回源单独列成一行。所以你真正要问的不是"能不能按量付费"，而是"按的是哪个量、超出之后单价多少、能不能把上限焊死"。

## 先分清：按量付费在按哪些"量"计费

大厂对象存储的账单通常长这样：

| 计费项 | 计费依据 | 容易踩的坑 |
| --- | --- | --- |
| 存储容量 | GB × 月 | 低频/归档层有最低存储期限，提前删除照样收费 |
| 请求次数 | 按万次计费，PUT/GET/LIST 单价不同 | 小文件多、爬虫抓图，请求费能超过存储费 |
| 下行流量 | 出外网的 GB 数 | 一次性被刷几十 TB，是最常见的爆账单原因 |
| 数据取回 | 归档层取回按 GB 收费 | 归档便宜是假象，取一次就还回去 |

按量付费本身没问题，麻烦在于这几项加在一起，月初中标一个量级，月末账单翻几倍。所以真正好用的按量付费，得配两个东西：一个看得懂的价格表，一个能关掉的总开关。

**个人博客图床**。假设文章配图 3000 张、平均 400KB，总存储约 1.2GB；每月图床流量波动大，写得勤的站点 30–80GB 是常见区间。这种情况宁波的「10G存储+50G流量」10 元/月就够了，甚至还有富余。

## 弹性计费开关：真正决定你会不会被刷爆

这一部分是按量付费里最该认真看的地方。

雨云对象存储超量后的默认行为是**停止访问**，不会自动开始扣费。想继续用，得自己去控制台把弹性计费打开。这个设计方向是对的——把"会不会产生额外费用"的决策权交回给用户。

打开之后，超量部分按前面那张表扣费，同时有几个保护机制：

- **开关随时可关**。发现流量异常抬升，直接关掉，超量部分不再计费。
- **自动止损**。官方产品说明提到，弹性计费开启状态下，一旦用完所有用量，系统会在 5–10 分钟内自动停止对应的上传或下载功能，避免持续欠费。这项机制来自官方发布说明，具体触发时间以实际控制台表现为准。
- **拆开禁用，而不是整个实例下线**。存储用量超了、又没开弹性计费，会禁用上传功能；流量超了会禁用下载功能。整个实例不会直接失联，桶里的文件仍然可以访问。
- **WAF 层拦一层**。对象存储自带防盗链（Referer 限制）、全局与单 IP 速率限制、超限后的 JS 验证、IP 黑白名单。这四样加起来，正是防"图片被别的站盗链、或者被人拿脚本狂刷下载"这类账单事故的关键。

把这几条串起来看，雨云这套按量付费的真实形态是：**套餐定预算，弹性计费定弹性，WAF 定防线，开关定底线**。跟"裸按量"比起来，最大的区别是你最坏情况下的账单是有天花板的。

## 按量付费省钱的几个实操点

- **上传不计流量**。往桶里传文件不扣流量，只有从桶里往外下载才扣。备份类场景基本只吃存储费。
- **同区域内网访问免费**。站点服务器和对象存储在同一区域，走内网地址读文件，上下行都不计流量。这条对图片站、附件站是实打实的省钱。
- **弹性变更套餐**。可以根据用量随时换套餐，升级补差价，也能降级。用量涨了就往上换，降下来再换回来，不必因为选错档位憋一整年。

## 常见问题

**上传要扣流量吗？**
不扣。只计算从存储桶下载产生的流量。

**请求次数收费吗？**
雨云的计费项只有存储空间和流量两项，不按 PUT/GET/LIST 请求次数单独收费。

**套餐用超了会怎样？**
默认停止访问。开了弹性计费则按超出单价扣费：宁波流量 0.1 元/GB、存储 0.5 元/GB；十堰流量 0.2 元/GB、存储 0.2 元/GB。

**超量了能只禁用一部分功能吗？**
可以，而且是系统默认行为：存储超量禁用上传，流量超量禁用下载，文件本身仍可访问。

**能不能先买小套餐再升级？**
可以。弹性变更套餐支持升级补差价，也支持降级。

**选宁波还是十堰？**
看你的用量结构。下载多、存储小 → 宁波；存储大、下载少 → 十堰。十堰的存储超量单价更低，宁波的流量超量单价更低。
